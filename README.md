CRUD and One-to-Many Relationship using FastAPI & SQLAlchemy

Description

This project demonstrates how to implement CRUD (Create, Read, Update, Delete) operations and establish a one-to-many relationship using FastAPI and SQLAlchemy. The project follows best practices for structuring FastAPI applications, using Pydantic for data validation and Alembic for database migrations.

Features

FastAPI for building RESTful APIs

SQLAlchemy for ORM and database interactions

Pydantic for request and response validation

Alembic for handling database migrations

One-to-many relationship implementation

Async database operations

Technologies Used

Python 3.9+

FastAPI

SQLAlchemy

Alembic

Pydantic

PostgreSQL (or SQLite for development/testing)

Uvicorn (for ASGI server)
